# P4.30.1 — 国家 / 行业标准文件的整理规则（草案）

> **状态**：已实现（2026-11-21）。识别与行级预处理 `guanlan/stdnorm.py`，层级 `guanlan/tocnorm.py`（`standard=True`），
> 接入 `guanlan/normalize.py`；错乱文字层检测在 `skills/pdf-to-markdown/scripts/convert.py`。§5 四项决策均按倾向裁定。
>
> **定位**：P4.30 §3 规范化整理的补充。国家标准（GB、GB/T、GB/Z）和按 GB/T 1.1 编排的行业标准
> （GA/T、SF/T、RB/T、JJF 等）结构高度统一：封面、目次、前言、引言、编号条款、术语条目、附录、参考文献。
> 现有整理规则对它们**大体适用**，但有五处与标准结构不合，另有一处转换层问题。本提案只补这些，
> 不改通用规则对其它文档的行为。
>
> **不推翻既有决策**。全部规则确定性、零 LLM（沿决策P4.30-3）；只在识别为标准文件时启用（§1）。

---

## 0. 动机与实测基线

取一份公开的国家标准（约 30 页、按 GB/T 1.1 编排、扫描件经 MinerU 4 `standard` 档 OCR 转换），直接跑现有 `normalize()`，不经入库。

| 环节 | 结果 | 判断 |
|---|---|---|
| 页眉 | 每页的标准号页眉全部删除 | 正确 |
| 页码 | 全部删除，前言罗马页码与正文阿拉伯页码分段计偏移 | 正确 |
| 跨页接句 | 接回的几处（含参考文献条目跨页）逐处核对均正确 | 正确 |
| 页脚注 | 压成引用块 | 正确 |
| 按目录定层级 | 认出「目次」，条目命中率超过 90%，`toc_applied: true` | 章、条两级正确 |
| `title` | 「中华人民共和国国家标准」 | **错**（§2.1） |
| 附录 | 「附录A / （资料性附录） / 附录名」三行标题未命中目次，落到最深一级；`A.1` 不认作编号 | **错**（§2.2） |
| 参考文献 | 第 2 级（跟随上一条「8.9」） | **错**（§2.3） |
| 术语条目 | 「## 3.1」单独一行，术语（中文 + 英文对应词）另成一个更深的标题 | 结构噪声（§2.4） |
| 无标题条 | 「7.3.2 ××方法应描述:」这类条款成了标题 | 结构噪声（§2.5） |

另外，国家标准全文公开系统下发的部分 PDF 文字层是错乱编码（`犌犅／犜`、`/G21/G22…`），
只读文字层的后端会产出乱码（§3）。

### 实现后实测（2026-11-21）

7 份公开标准（国标 4 份、公共安全行业标准 1 份、司法行政行业标准 1 份、司法鉴定技术规范 SF/Z 1 份），
MinerU 4.2 `standard` 档转换后，同一份产物分别关、开标准模式整理：

| 项目 | 结果 |
|---|---|
| 识别 | 7/7 认出；另在 7470 份非标准文档（法规、论文、书籍）上零误报 |
| 标题 | 7/7 改为「标准号 标准名称」；原先取到的是「中华人民共和国国家标准」「司 法 鉴 定 技 术 规 范」等 |
| `standard:` | 7/7 写出标准号与发布、实施日期；有代替、采标的都抽到 |
| 目次 | 一份 28 页国标命中由 39/41 升到 41/41；其余带目次的不变；没有目次的 3 份照常 |
| 术语条目 | 6 份合并，2–264 条不等（一份术语标准 264 条全部合成「3.1.1 术语 英文」，第 3 级） |
| 附录 | 有附录的一份 2 处合并，与章同级；`A.1` 与 `4.1` 同级 |
| 无标题条 | 降为正文 1–2 处；目次条目未受影响 |
| 跨页接句 | 一份 5 页国标少接 1 处：原先把页尾残留的页码「2」接到下一页的「3.1.3 …」前面，属于误接 |
| 页眉、页码 | 删除数与原规则相同 |

实测中发现并已修正：封面上的标准号行与每页页眉相同、又落在第一页页首窗口里时，会先被页眉规则删掉，
导致识别不到。识别因此移到去噪之前（§1）。

**规则修不了的（转换层）**：一份行业标准里，MinerU 把部分条款编号整个丢了（「6.1 记录检材情况」只剩
「记录检材情况」），没有编号可依，层级照转换器输出。

## 1. 何时启用：标准文件识别

识别在去噪**之前**做（实测补充：封面标准号行常与页眉相同，先去噪会把它删掉）。**只看第一页**（首个分页锚点到第二个锚点之间；无锚点时取正文前 40 个非空行），以下两条**同时**成立才判为标准文件：

1. **标准号行**：整行（去掉标题标记、粗体后）以标准代号开头、带年份：
   `^(GB(/[TZ])?|GA(/T)?|SF/[TZ](\s*JD)?|RB/T|JJ[FG]|[A-Z]{2}(/[TZ])?)\s*[\d.]+\s*[—–\-]+\s*\d{4}`，
   允许其后跟 `/ISO…` 采标标识。
2. **标准封面特征**，满足其一：
   - `ICS` 分类行（`^ICS\s*\d{2}\.\d{3}`）；
   - 「中华人民共和国国家标准」「中华人民共和国××行业标准」「司法鉴定技术规范」之一的整行；
   - 同页同时出现「××发布」和「××实施」两个日期行。

识别结果写入 `normalized.profile: standard`。不满足就按原规则处理，**不出现半启用**。

**能力上限**：只认第一页是封面的原件。汇编（多份标准合订一册）、只截了正文的片段、封面是图片且没有 OCR 出文字的，
都不会被识别，按通用规则处理。标准号行被转换器拆成两行（`GB/T` 与 `12345—2020` 分行）时同样认不出；
这种情况实测前不处理。

## 2. 标准模式下的整理规则

按 P4.30 §3 的固定顺序插入：§2.1 在写 frontmatter 时；§2.2–§2.5 在 §3.5 按目录定层级**之前**做行级预处理，
让目次比对和层级判断看到的是合并好的行；§2.6 作用于 §3.4 跨页接句。

### 2.1 标题取「标准号 标准名称」

- **标准名称**：封面上标准号行（及「代替…」行）之后、第一个英文行或「发布」日期行之前的中文标题行。
  转换器把长名称拆成两行标题（「示例科学 某物质检验」/「某色谱法」）时，连续的中文标题行按一行拼接，
  中间补一个全角空格。
- `title` 写成 `GB/T 12345—2020 示例实验室能力通用要求`，标准号保持原件写法（全角破折号不改）。
- 取不到名称时退回原规则（首个一级标题，再退文件名），并在操作日志记一条 `standard_title_fallback`。
- 封面上「中华人民共和国国家标准」这类行仍按 §3.5 降级，不删除。

**结构化字段（决策P4.30.1-1）**：同时写一组字段，供入库时 Agent 直接引用：

```yaml
standard:
  code: GB/T 12345—2020
  replaces: [GB/T 12345—2010]
  adopts: ISO 99999:2019, IDT
  issued: 2020-01-01
  effective: 2020-07-01
```

字段全部从封面原文抽取，抽不到就不写该键，不猜测。

### 2.2 附录：合并多行标题，与章同级

1. **合并**：标题行「附录 X」（X 为大写字母，允许与「附录」之间有空白）之后紧接的
   「（规范性附录）」「（资料性附录）」「（规范性）」「（资料性）」行，以及其后一行**非编号**的短标题
   （≤ 40 字，不以句末标点结尾），合成一行：`附录A （资料性附录） 计量溯源性`。原来的标题标记、普通文本都可以参与合并，
   但最多向后看 3 个非空行，中间遇到分页锚点、表格、列表即停。
2. **编号形式**：`_MARKERS` 增加 `appendix`（`^附录\s*[A-Z]`）和 `appendix-multi`（`^[A-Z]\.\d{1,3}(\.\d{1,3})*`，
   按点数分级，与 `num-multi` 同一套深度规则）。
3. **层级**：标准模式下，`appendix` 与目次中第 1 级编号形式同级；`A.1` 与 `1.1` 同级，`A.1.1` 与 `1.1.1` 同级。

### 2.3 固定要素一律第 1 级

标准模式下，目次条目与正文标题若整行（去编号、空白后）为下列之一，层级固定为 1，不跟随上一条：
**前言、引言、参考文献、索引**。这改的是 `_assign_levels` 中「无编号条目与上一条同级」这条，只在标准模式下改。

### 2.4 术语条目：编号与术语合成一行

- 识别：「3 术语和定义」这一章内，整行只有多级编号（`3.1`、`3.1.2`）的行，紧跟的下一个非空行是术语
  （中文词语，可带英文对应词，≤ 60 字，不以句末标点结尾）。
- 合并成一行 `3.1 公正性 impartiality`，层级按 `num-multi` 规则（与 `4.1` 同级）。
- 不在「术语和定义」章内的孤立编号行不动。

### 2.5 无标题条降为正文

标准里大量条款没有条标题，编号后直接是要求（「7.3.2 抽样方法应描述:」）。转换器常把它们输出成标题。

- 识别：带编号形式（`num-multi` / `appendix-multi`）的标题行，编号后的文字满足其一：
  以 `：:。；` 结尾；或含「应 / 宜 / 可 / 不应 / 应当」且长于 20 字。
- 处理：去掉标题标记，作为普通段落保留，一字不改。
- **目次里有的不降**：命中目次条目的行永远保持标题。
- **能力上限**：「7.2 方法确认」这类真正的条标题不受影响；但条标题本身恰好以冒号结尾的极少数情况会被误降。

### 2.6 跨页接句：补充结构标记

标准模式下，「下一页首段以结构标记开头就不接」的标记表（`_STRUCT_START_RE`）增加：

| 形式 | 例 |
|---|---|
| 多级编号 | `5.2.1 `、`A.3 ` |
| 列项 | `a)`、`b）`、`1)` |
| 注、示例 | `注：`、`注 1:`、`示例 2：` |
| 图表题 | `表 1`、`图 A.2` |
| 附录 | `附录 B` |

**只在标准模式下加**：在通用文档里，页首的「1.5 倍」这类续句会被误判为编号而不接回。
这是否决规则，只会让接句更保守，不会产生新的误接。

## 3. 转换层：错乱文字层

国家标准全文公开系统下发的部分 PDF 使用私有编码字体：文字层里 `ICS` 变成 `犐犆犛`，
`GB/T` 变成 `犌犅／犜`，另有大量 `/G21` 形式的字形名。错乱的是拉丁字母和数字（代号、英文术语、单位），
中文正文本身正常。pypdf 后端照抄这层文字。

1. **检测**（`pdf-to-markdown` 技能 `scripts/convert.py` 的 `garbled_text_layer`，在每个后端产出之后检查）：
   满足任一条即判定为错乱文字层：
   - `/G[0-9A-F]{2}` 字形名 ≥ 20 处；
   - U+7280–U+72FF 区段里**不在 GB2312 中**的字符 ≥ 20 个，且只数连续出现的（一串里至少 2 个）。这个区段也有
     「犯」「状」「独」「狗」等常用字，它们都在 GB2312 里；繁体常用字「狀」「犧」「狹」不在 GB2312，但在正文里单个出现；
     错乱字形则成串拼出整个单词（「犐犆犛」「犌犅」）。起草时设想的「占中文字符比例 ≥ 5%」被实测否掉：
     正常的刑事类文档里「犯」字就能让比例到 7–8%。
2. **处理**（只对 PDF 输入）：判为错乱的产物算这个后端失败——删掉产物、在 stderr 写明原因、换下一个后端；
   全部后端都失败则非零退出，不静默交出乱码。
3. **MinerU 4 不需要额外处理**：实测一份文字层错乱的公开国家标准（40 页），MinerU 4.2 `standard` 档产出完全正确，
   说明它不照抄这类文字层。起草时设想的「MinerU 产物错乱时改用 OCR 重跑」因此不做；万一某个档位产出错乱，
   第 2 条照样把它判为失败。

## 4. 不做

- 不处理扫描件上的一次性杂讯（如单页上的贴纸、印章文字）。水印规则按设计只删跨页重复且整行匹配明确模式的行（P4.30 §3.3.1）。
- 不解析表格、公式内容，不校验条款编号连续性。
- 不改 `guanlan convert` 的行为。`convert` 只转换不整理（P5.2）；用 `convert` 产出的标准 md
  不会自动得到本提案的整理。是否给 `convert` 加 `--normalize` 另议（决策P4.30.1-3）。
- 不识别汇编型文档里的多份标准（§1 能力上限）。

## 5. 决策（2026-11-21 裁定，均按倾向）

- **决策P4.30.1-1**：写 `standard:` 结构化字段（§2.1），只含从封面原文抽到的键。
- **决策P4.30.1-2**：标准模式自动识别、不设开关（§1）。沿 P4.30「用户不参与清洗规则」的使用原则；
  识别结果写进 `normalized.profile`，可事后核对。
- **决策P4.30.1-3**：`guanlan convert --normalize` 另起提案，不在本期。
- **决策P4.30.1-4**：§2.6 的补充标记只在标准模式启用，不改通用接句行为。

## 6. 测试要点

- **识别**：GB/T、SF/T、GA/T、SF/Z JD 封面各一份正例；正文里引用国家标准号的普通文档、法规汇编、
  只有标准号没有 ICS 和封面特征的片段各一份反例（不得启用）。
- **标题**：单行名称、两行名称、取不到名称时的退回。
- **附录**：三行拆开的附录标题合并后命中目次、层级为 1；`A.1` 与 `1.1` 同级；
  正文里「参见附录 A」这类句子不被合并。
- **固定要素**：参考文献、前言在编号条目之后仍为第 1 级。
- **术语**：「3.1」+ 术语行合并；术语章外的孤立编号行不动。
- **无标题条**：「7.3.2 抽样方法应描述:」降为正文；「7.2 方法确认」保持标题；**目次里有的条目不降**。
- **接句**：页首「5.2.1 …」「a) …」「注 1:」不接；通用模式下页首「1.5 倍」照接（不受影响）。
- **漏报反例**（每条过滤规则配一条「本该保留却可能被吞掉」的用例）：无标题条规则不得降掉目次条目；
  附录合并不得吞掉附录后紧跟的「A.1 总则」；错乱检测不得在正常中文 PDF 上触发。
- **回归**：用 §0 的同一份样本跑全流程，表中「正确」的各项结果不变。
- **样本与夹具**：真实标准原件和转换产物都不进仓库（标准文本有版权，仓库是公开的）。单元测试夹具按标准的版式
  **自行编写**（虚构的标准号、名称和条文，只模仿封面、目次、附录、术语条目的结构）；
  另需覆盖四类原件：文字层正常、扫描件、错乱文字层、大体积扫描件，校准在本地用公开标准完成，结论写回 §0。
