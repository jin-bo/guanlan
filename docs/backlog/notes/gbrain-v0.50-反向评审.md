## 1. 🟢 P5.3 的权重没有证据，语料也测不出区分度（gbrain 0.48.4 ranker wave）

**gbrain 的事实。** 0.48.4 一次修了两个"发布很久才被自家收据抓到、不是用户报的"排序默认值：融合后的 metadata boost（backlinks / recency / 图邻接）在**只有向量臂投票**时把连接良好的枢纽页顶到真正命中的页之上（修法 `metadata_boost_gate: lexical`）；autocut 看着省 token，实测把多源问题的 strict `recall_all@5` 从 449/470 砸到 379/470。真正可借的是**纪律**：每个移动过的默认值都带**预注册收据**——先声明判据和阈值、再跑、不过线就把旋钮以 `off` 发布；且**调参用 dev slice、公布用全集**，不在回归闸那组题上调参。

> **修订（论证纠偏）**：初稿称观澜"栽的是同一个坑"，**不成立**——gbrain 那条门的触发条件是"只有向量臂投票"，观澜 BM25 是**唯一臂**、每次命中都是 lexical，不存在对应形态。可借的是**同一类风险**，不是同一个 bug：一个**查询无关的文档先验**乘在弱命中上，可能把弱相关枢纽页抬过正确页。

**观澜对照（两道检查都过了）。**

- [`guanlan/search.py`](../../../guanlan/search.py)`:62` `BACKLINK_WEIGHT`（**评审时为 0.5**，现已改为 0.05，见 §1.1）—— [`P5.3`](../../P5.3-检索backlink重排.md) §1 / 决策P5.3-2 只有直觉论证（"10 入链 ×2.2、1 入链 ×1.35，温和、不喧宾夺主"），**没有任何实测、扫描或"效果"节**；§6 测试要点是**机制**测试（零反链不归零、memo 失效面），不是效果测量。
- [`tests/test_search_quality.py`](../../../tests/test_search_quality.py) 的断言方向**是对的**——`test_boost_is_live_and_never_demotes_primary`（`:378`）确实断言 boost 不把正确页压到纯 BM25 之下。**缺的不是断言，是困难语料**：docstring `:28` 自陈"每条 `GOLDEN` 的 primary 页都把 query 词放进**标题**，故字段加权下 rank-1 稳健"，于是 primary 本就以大比分领先、boost 无从改变名次，三条聚合断言恒等于 1.0（`:344-346`）——**W 取 0、0.5 还是 2，这组闸都绿**。它能挡分词/BM25 参数被改崩，挡不住文档先验的取值。

**风险量级（上界估算，非断言必然翻转）。** 因子 `1 + 0.5·ln(1+c)`：`c=10` → ×2.2，`c=30` → ×2.7。即一个入链 10 的枢纽页，纯 BM25 分**只要不低于正确页的 45%** 就可能翻上来（入链 30 时降到 37%）。是否真翻取决于两页的实际分差——而现有语料里这个分差被构造得极大，所以观察不到。真实库里 `concepts/` 枢纽页几十条入链、正文长（长度归一后仍常拿中等分），正确答案却常是零入链的新 source 页。

**落法（零 LLM、不碰内核）。**

1. **补困难样例**（`CORPUS` 加一小组）：**正确答案只出现在正文**（标题与别名都不含 query 词）+ **弱相关枢纽页高入链**。这才让 W 有区分度。
   > **修订**：初稿提的"低入链页**标题精确命中** vs 高入链枢纽页正文命中"**仍在沿用旧偏置**（正确页照样靠标题赢），删。
2. **一次性权重对照**：`W ∈ {0, 0.25, 0.5, 1, 2}` 在困难样例 + 现有黄金集上跑，表写进 P5.3 新开的"效果"节。
3. **结论允许否定现值**：若 `W=0.5` 在困难样例上输，就**调低或把 boost 关掉**（`W=0` 即逐字节回退到纯 BM25，决策P5.3-2 的公式本就保证这点）。P5.3 的默认值是可撤的，不预设"维持现值"。
   > **修订**：初稿写"不过线就维持现值、而不是把测试改绿"——前半句错，删。不过线的正确反应是改默认值，不是留着它。

**红线**：仍在查询期算、不落派生物（P5.0 stateless 不破）；不改收录门槛（决策P5.3-7 不破）；不引入运行时 `eval` 子命令与持久 ledger（§6"过重"档，只借纪律）。

## 2. 🟡 数字字面缺失提示（待验证实验，**不接写门禁**）

**gbrain 的事实。** 0.47.8 写路径蒸馏波在合成页落盘前做机械引文核验/修复（精确留 / 漂移替换 / 定位不到就摘引号留文字），并附一项 **warn-only 计数：页上出现、原文里找不到的数字与日期**。实测引文保真 54% → 83%。两个实现坑：定位按**完整码点**推进，否则 emoji / CJK 歪 offset（#4706）；**存在性检查与修复必须共用同一套折叠函数**，否则折叠改变字符长度时会把乱码当"逐字修复"拼进页面（0.47.8 Fixed 的土耳其点 I）。

**观澜对照。** [`guanlan/gate.py`](../../../guanlan/gate.py) 的写门禁全是**结构级**（`raw/` 快照、`sources` 不丢、`body.shrank`、frontmatter 复验）；[`guanlan/provenance.py`](../../../guanlan/provenance.py) 的 `raw_digest` + [P3.7 audit](../../P3.7-语义审计.md) 管的是**源变了没重综合**。没有任何一处检查页上的数字在源里有没有出现过。

> **修订（能力上限，初稿高估）**：这条**只能测字面存在，不能证明事实有据**，改称**「数字字面缺失提示」**而非"事实核验"。两类硬失败：
> - **张冠李戴照过**：原文"收入增长 37%"、摘要写成"利润增长 37%"——`37%` 在源里找得到，零告警。
> - **合法派生误报**：原文"从 100 增至 120"、摘要写"增长 20%"——`20%` 源里没有，反而报警。
> 中文数字 / 单位（万·亿）/ 日期格式的归一**只会扩大规则面与维护成本**，改变不了这个上限。

> **修订（来源定位口径，初稿写错）**：初稿说"只对有 `sources:` 且能经 `admit_raw_path` 定位 raw 的页跑"——错。`sources:` 装的是**来源页 slug**，不是 raw 路径；`admit_raw_path` 只做路径准入；source 摘要页与 raw 的关联在**自身 `raw_digest`**（`parse_digest_value` 解出 raw 相对路径 → `admit_raw_path` 准入）。按初稿口径会把最该测的对象搞错。**最小实验只覆盖带有效 `raw_digest` 的 source 页，不做多源追溯。**

> **修订（过头话收回）**：初稿称"`raw/` 不可变让『模型当时看到的文本』免费、比 gbrain 更便宜"。`raw/` 不变只证明**文件字节稳定**，**不证明模型读过全文**（长源截断、未开 vision 的图注、分段读取都可能只看了一部分）。删。

**路线（按"先验证再接入"走，不进本轮排期）。**

1. **离线抽样**：脚本跑现有库的 source 页，人工核一批告警，量出**误报率**与误报类型。
2. 误报率过线才考虑接 `lint` **advisory**（riding `EXIT_LINT_FINDINGS`）；不过线就**丢掉这条提案**。
3. **任何阶段都不接写门禁**（初稿提的"同 `body.shrank` 档的门禁警告"撤回）——门禁噪音的代价比这条提示的收益大。
4. 若真要做：归一函数**报与不报共用同一个**、按码点推进、**宁漏不误**，并配一条本该报出的正例防漏报。
